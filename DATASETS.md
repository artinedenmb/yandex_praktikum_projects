# Данные для проектов

Исходные тетради читают файлы из `/datasets/` в учебной среде Яндекс Практикума. Прямые ссылки на доступные CSV указаны в README соответствующих проектов; доступность этих ссылок проверена 13 октября 2026 года. Данные из папок `/datasets/faces/` и `/datasets/final_provider/` доступны в среде курса, но прямые ссылки по этим путям не работают.

В репозитории сохранены авторские тетради и созданные в них HTML-отчёты. Наборы данных не копировались в GitHub. Для запуска проектов вне Практикума скачайте данные по ссылкам и поправьте абсолютные пути `/datasets/...` на местоположение файлов на вашем компьютере.
