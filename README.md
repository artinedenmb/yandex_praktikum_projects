В папках проектов указаны исходные пути к данным и проверенные ссылки на доступные CSV. Подробнее: [данные для проектов](DATASETS.md). Сами учебные датасеты не включены в репозиторий: они предоставляются Практикумом и могут быть объёмными. Аналитические HTML-отчёты, созданные в Jupyter, приложены к соответствующим работам. В выпускном проекте также сохранены промежуточные версии, а в проекте по компьютерному зрению — отдельная тетрадь с исследованием данных.

Содержимое тетрадей не изменялось при переносе.
